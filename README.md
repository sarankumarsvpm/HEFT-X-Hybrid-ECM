# HEFT-X – Hybrid Emergency Fuel Transition

### Intelligent Parallel Hybrid Vehicle ECM

**Two Power Sources. One Intelligent Performance System.**

## 🚗 Project Overview

HEFT-X is an innovative hybrid vehicle ECM concept designed to combine petrol engine power and electric motor performance.

The system is designed with three operating modes:
1. Petrol Mode
2. Emergency Battery Mode
3. Track Mode

## ⚙️ Proposed Vehicle Specifications

### Petrol Engine
- Power: 150 PS
- Torque: 250 Nm
- Fuel: Petrol

### Electric Powertrain
- Battery Capacity: 79 kWh
- Motor Power: 282 PS
- Motor Torque: 380 Nm

### Emergency Battery Mode
- Target Range: 100 km
- Electric-only driving when petrol fuel is empty.
- Automatic transition to battery-powered operation.

## 🔋 Operating Modes

### 1. Petrol Mode
The vehicle operates using the petrol engine as its primary power source.

### 2. Emergency Battery Mode
When the petrol fuel tank becomes empty, the ECM is designed to request electric-only driving using the battery and electric motor.

### 3. Track Mode
The petrol engine and electric motor work together using a parallel hybrid architecture.

The objective is to achieve combined power delivery for enhanced performance.
